## Entry

> I told the printer it was out of paper, so it printed a 40-page error report to prove me wrong.

95 characters, one line. The printer's "proof" is a 40-page error report — the complaint about the printer becomes the printer's own punchline.

## Program

`main.py` (Python 3, stdlib only, deterministic) writes the joke to `/output/entry.txt`.

```sh
python3 main.py
```
